# PROMPT REPLIT — DESENVOLVIMENTO DO VERDANT CONTROL
## Plataforma SaaS de Gestão Ambiental Inteligente com Inteligência Artificial

Quero desenvolver uma plataforma SaaS chamada **VERDANT CONTROL**, vinculada à marca VERDANT AMBIENTAL, para gestão ambiental empresarial, controle de obrigações legais, licenciamento, gestão documental, resíduos e automação de processos ambientais.

ATENÇÃO: Não quero uma simples interface demonstrativa. Quero desenvolver um sistema real, com banco de dados, autenticação, armazenamento de arquivos, cadastros funcionais, controle de vencimentos, dashboards, permissões e estrutura preparada para integração com inteligência artificial.

O objetivo é transformar o software em um produto comercializável por assinatura para indústrias e empresas de diferentes segmentos.

Todo o sistema deverá ser desenvolvido em português brasileiro.

---

# 1. CONCEITO DO SISTEMA

O VERDANT CONTROL deverá funcionar como um consultor ambiental digital, centralizando as informações ambientais de uma empresa e orientando os usuários sobre o que precisam fazer, quais documentos devem apresentar e quais obrigações precisam cumprir.

O sistema deverá:

- Centralizar todos os documentos ambientais.
- Interpretar documentos utilizando inteligência artificial.
- Identificar obrigações legais e condicionantes.
- Controlar licenças, autorizações e vencimentos.
- Monitorar documentos e obrigações.
- Orientar os usuários sobre as alimentações necessárias.
- Controlar MTR, CDF e rastreabilidade de resíduos.
- Organizar informações do IBAMA, CTF/APP, RAPP e TCFA.
- Criar tarefas e planos de ação.
- Enviar notificações automáticas por e-mail.
- Gerar relatórios gerenciais.
- Manter histórico de alterações e evidências.
- Permitir acompanhamento por consultorias ambientais externas.

A plataforma deve ser desenvolvida com arquitetura multiempresa (multi-tenant), permitindo que diferentes empresas utilizem o sistema sem compartilhar informações entre si.

## Inteligência artificial documental

Quando um usuário enviar um documento, a IA deverá:

1. Identificar o tipo de documento.
2. Extrair informações relevantes.
3. Identificar número e órgão emissor.
4. Extrair datas de emissão e validade.
5. Identificar obrigações e condicionantes.
6. Identificar frequências e prazos.
7. Sugerir categoria documental.
8. Identificar documentos complementares necessários.
9. Apresentar as informações extraídas para validação humana.

Não cadastrar automaticamente informações legais críticas sem aprovação do usuário.

A IA deverá preservar a referência ao documento original e permitir que o usuário confira de onde cada informação foi extraída.

Criar status:
- Aguardando análise.
- Analisado pela IA.
- Aguardando validação.
- Validado.
- Rejeitado.
- Vencido.

## Funcionamento

O sistema deverá executar verificações automáticas diariamente.

Quando uma data de alerta for atingida:
1. Identificar o documento.
2. Identificar os destinatários.
3. Gerar o e-mail.
4. Enviar a mensagem.
5. Registrar o envio.
6. Armazenar histórico.
7. Evitar envio duplicado.

Criar modelos de e-mail profissionais.

Exemplo:

Assunto: Alerta de vencimento – Licença de Operação.

"Prezados,

Informamos que o documento Licença de Operação nº XXX, vinculado à unidade XXX, possui vencimento previsto para 30/06/2027.

Faltam 60 dias para o vencimento.

Solicitamos que sejam iniciadas as providências necessárias para renovação.

VERDANT CONTROL."

Preparar integração com SMTP ou provedor de e-mail transacional.

Criar uma tela de histórico de notificações com:

## Requisitos do VERDANT AI

1. Utilizar os dados reais da empresa autenticada.
2. Respeitar permissões de acesso.
3. Consultar documentos cadastrados.
4. Responder com referências aos documentos.
5. Identificar quando não possui informações suficientes.
6. Não inventar leis, prazos ou obrigações.
7. Diferenciar informação extraída de documento e interpretação da IA.
8. Informar quando determinada conclusão exige validação técnica.

Criar interface de chat moderna, com histórico de conversas.

Preparar integração com API de inteligência artificial.

Não colocar chaves de API no frontend.

1. Desenvolver funcionalidades reais, não apenas telas ilustrativas.
2. Não criar botões sem funcionalidade.
3. Não simular envio de e-mail como se fosse real.
4. Não simular processamento de IA sem integração.
5. Não utilizar dados fictícios como se fossem dados reais.
6. Não deixar informações de empresas acessíveis entre diferentes contas.
7. Não armazenar documentos apenas localmente.
8. Não inventar obrigações legais.
9. Não permitir transmissão oficial sem autorização humana.
10. Não criar dependência de um único fornecedor de IA.
11. Documentar as integrações e variáveis de ambiente.
12. Criar migrations e instruções de instalação.
13. Testar os principais fluxos.
14. Corrigir erros de compilação.
15. Garantir responsividade.

Se alguma integração depender de credenciais externas, preparar sua estrutura e indicar claramente quais credenciais são necessárias.

# RESULTADO ESPERADO

Entregar uma plataforma SaaS profissional, funcional e escalável, que permita a uma empresa administrar praticamente toda sua rotina ambiental em um único ambiente.

O grande diferencial do VERDANT CONTROL deverá ser a combinação de:

**GESTÃO DOCUMENTAL + INTELIGÊNCIA ARTIFICIAL + CONTROLE DE OBRIGAÇÕES + AUTOMAÇÃO DE ALERTAS.**

O sistema não deve ser apenas um arquivo digital de documentos. Ele deve orientar o usuário sobre o que precisa ser feito, quando precisa ser feito, quais documentos são necessários e quais pendências precisam ser resolvidas.

Comece pela arquitetura e pela Fase 1. Após concluir cada fase, teste o funcionamento antes de avançar. Preserve o código e as funcionalidades já implementadas.
